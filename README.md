# React Exam Project

React + Vite სასწავლო პროექტი, რომელიც აერთიანებს კომპონენტებს, Props/PropTypes, Hooks, Context, Fetch API, React Router, Redux Toolkit და react-hook-form/Yup.

## გაშვება

```bash
npm install
npm run dev
```

Vite ტერმინალში გაჩვენებს ლოკალურ URL-ს.

## შემოწმება

- მთავარი გვერდი: `/`
- პროდუქტები: `/products`
- პროდუქტის დეტალი: `/product/1`
- კონტაქტი: `/contact`
- API: `https://jsonplaceholder.typicode.com/posts/1`

## Build შემოწმება

```bash
npm run build
```

შენიშვნა: API მოთხოვნისთვის საჭიროა ინტერნეტი. `useEffect`-ის ლოგი React StrictMode-ის დეველოპერულ რეჟიმში შეიძლება ორჯერ გამოჩნდეს.
